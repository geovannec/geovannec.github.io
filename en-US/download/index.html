Verify before installing

Each release includes SHA256SUMS.txt signed with cosign keyless (CI OIDC identity, recorded in the Rekor transparency log) and a full SBOM.

  1. Download the binary and SHA256SUMS.txt from the same release.
  2. Check the downloaded file's hash against the manifest.
  3. Verify the cosign signature on the manifest.
  4. Compare with the SBOM if you need to audit dependencies.
shasum -a 256 SovereignSocial*
cosign verify-blob --bundle SHA256SUMS.txt.bundle SHA256SUMS.txt

SBOM and provenance

Each release publishes an SBOM (SPDX) with all dependencies and the pipeline's SLSA provenance — know exactly what you're installing.
