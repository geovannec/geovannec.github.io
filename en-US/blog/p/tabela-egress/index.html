What leaves your computer: the egress table

2026-11-05 · Privacy

Most apps ask for trust. We'd rather show the inventory.

Every network egress path in Sovereign Social is registered in an EGRESS_REGISTRY in the source code — and the site's privacy page is generated from that table at build time. If code and page diverge, CI fails.

What the table shows, unvarnished:

  • Nostr relays — the ones you configured; that's the protocol's transport.
  • oEmbed/embeds — only when a post references external media.
  • App update check — release lookup, opt-in.

And what doesn't exist: analytics, default-on telemetry, calls to a project server, fingerprinting. There's no "phone home" channel — the threat model is public and the table is auditable in the code.

If you ever see a new egress row, it will come with purpose and control documented — because the table is the code.

This post is also published as a Nostr long-form article (NIP-23) under the project's key.
