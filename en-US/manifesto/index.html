Manifesto

Why it exists

The communities that shaped the early web — forums, scraps, testimonials — were shut down by commercial decisions. Sovereign Social exists so the next generation of communities doesn't depend on a company's quarterly balance sheet.

It is local-first software: the app runs on your computer, keeps your data in a SQLite you own, and talks to Nostr relays — interchangeable public servers — to sync.

The Five Non-Negotiables

Five principles define what this project will never do:

  • Zero infrastructure cost — no paid server the network depends on.
  • Zero proprietary media — no binaries on relays or in the database, only URLs and metadata.
  • Zero ads and zero tracking — no default-on telemetry, analytics or ad SDKs.
  • User sovereignty — you control keys, data and filters; nobody deletes content from the network, only hides it in your client.
  • Auditable open source — all code public, no proprietary components in the core.

What this means in practice

Your account is a key pair generated on your device. There is no e-mail, no password reset, no third-party suspension — which is why your 24-word backup is treated like an important document.

If a relay turns hostile or disappears, you switch relays. If the project dies, the code and your data stay with you — that's the difference between a user and a hostage.

Honest about limits

The project is in alpha. Public relays see publishing metadata (when and where you post). Network deletion is best-effort: NIP-09 requests don't guarantee removal of already-propagated copies. We document limits because trust is built with facts.
