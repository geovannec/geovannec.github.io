Security

Threat model

The public threat model documents what we protect (private keys, local data, event integrity) and against whom (malicious relays, local-network MITM, hostile web pages).

The local server accepts loopback connections only, with an anti-DNS-rebinding origin gate, per-launch CSRF token, step-up auth on destructive actions and per-route rate limiting.

Audits and reviews

Security reviews already completed, all public in the repository:

  • MVP and V3 security audits (docs/AUDITORIA_SEGURANCA_MVP.md, SECURITY_AUDIT_V3.md).
  • NIP-41 key rotation and Shamir (SLIP-39) backup audit with official vectors in CI.
  • CodeQL, OpenSSF Scorecard and weekly CVE scans with SBOM in the pipeline.

Report a vulnerability

Use GitHub Private Vulnerability Reporting (Security tab → Report a vulnerability). SLAs: acknowledge in 72h, triage in 7 days, fix in 30 days; coordinated disclosure within 90 days.

If the private channel fails, open a minimal issue saying only 'security concern — please contact me', with no details.

Verify your download

SHA256SUMS signed by cosign keyless, per-release SBOM and verification instructions on the download page. Reproduce the build if you want full proof.
