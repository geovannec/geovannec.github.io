Roadmap

Como ler este roadmap

O plano de sprints completo (docs/08_PLANO_DE_SPRINTS_V4.md) é a fonte de verdade — esta página resume marcos públicos. Datas não são promessas; o projeto é mantido por uma pessoa.

Entregue

  • Core Nostr: identidade local, relays, sync, busca FTS5, takeout.
  • Comunidades, tópicos wiki, scraps, depoimentos, blog e álbuns.
  • Hardening: rotação NIP-41, backup Shamir, VDP, supply-chain assinado.
  • i18n pt-BR/en/es, WCAG 2.2 AA auditado, ACR EN 301 549/508.

A seguir

  • Pesquisa com usuários reais (painel em recrutamento).
  • Site público e docs site com tutoriais e press kit.
  • Comunidades fundadoras e outreach (consent-based).
  • Launch público — gate G3 depende de revisão humana.

O que nunca entra

Ads, tracking, algoritmo de engajamento, contas hospedadas, tokens/cripto-especulação. Se um dia aparecer, o manifesto falhou.
