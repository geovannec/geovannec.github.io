# Fact sheet — Sovereign Social

| | |
|---|---|
| **O que é** | Rede social/fórum local-first, open-source, sobre o protocolo Nostr |
| **Licença** | AGPL-3.0 |
| **Stack** | Python 3.12+, SQLite (aiosqlite + FTS5), FastAPI, Jinja2 + HTMX |
| **Protocolo** | Nostr (NIP-01 e outros) — 68 event kinds registrados |
| **Identidade** | Par de chaves secp256k1 no dispositivo; backup por 24 palavras ou Shamir (SLIP-39) |
| **Moderação** | Por comunidade — vereditos públicos, sem deleção central |
| **Mídia** | URL + metadados (NIP-94) — nenhum binário em relays |
| **Idiomas** | pt-BR, en-US, es-419, es-ES |
| **Acessibilidade** | WCAG 2.2 AA auditado; ACR EN 301 549 / Section 508 publicado |
| **Plataformas** | Windows, macOS, Linux (desktop via pywebview) |
| **Preço** | Gratuito — sem anúncios, tracking ou telemetria |
| **Status** | Alpha (pré-launch) |
| **Código-fonte** | https://github.com/geovannec/pnet |

## Uma frase

"Sovereign Social é uma rede social local-first onde a sua conta é uma
chave no seu dispositivo — não um registro no servidor de uma empresa."
