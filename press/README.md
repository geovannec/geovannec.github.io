## Embargo e previews

- Pedidos de embargo: abra uma issue marcada `press` ou contato via
  security.txt se sensível. Respeitamos embargos razoáveis — pedimos data
  e escopo por escrito.
- Downloads embargo-safe: use os binários de release públicos do
  repositório — não distribuímos builds privadas para imprensa; o que a
  imprensa roda é exatamente o que um usuário baixa.
- Preview de features: branches `feat/*` públicas podem ser citadas como
  "em desenvolvimento" — marque como tal.

## Regras de uso da marca

- Use os SVGs como estão; não recolore a marca para sugerir afiliação.
- "Sovereign Social" com espaço e iniciais maiúsculas.
- O projeto é software livre (AGPL-3.0) — atribuição bem-vinda, não exigida.
