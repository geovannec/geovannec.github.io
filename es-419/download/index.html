Verifica antes de instalar

Cada release incluye SHA256SUMS.txt firmado con cosign keyless (identidad OIDC del CI, registrada en el transparency log Rekor) y SBOM completo.

  1. Descarga el binario y el SHA256SUMS.txt del mismo release.
  2. Confirma el hash del archivo descargado contra el manifiesto.
  3. Verifica la firma cosign del manifiesto.
  4. Compara con el SBOM si necesitas auditar dependencias.
shasum -a 256 SovereignSocial*
cosign verify-blob --bundle SHA256SUMS.txt.bundle SHA256SUMS.txt

SBOM y procedencia

Cada release publica un SBOM (SPDX) con todas las dependencias y la procedencia SLSA del pipeline — sabe exactamente qué estás instalando.
